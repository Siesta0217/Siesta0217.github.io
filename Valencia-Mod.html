▘ OVERVIEW

README

Valencia is a Fabric client mod for Lunar Client 1.21, built from scratch with no Fabric API dependency. Features a draggable ClickGUI, persistent JSON config, in-game keybind rebinding, and a growing set of modules across Combat, Movement and Render categories. Uses pure GuiGraphics rendering — Sodium / Iris compatible.
