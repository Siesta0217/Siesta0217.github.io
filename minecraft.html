T-Display-S3-Touch Smart Clock

This project uses a T-Display-S3-Touch board to build a smart desktop clock. It focuses on accurate second display, custom wallpaper support, and weather monitoring, so the device can work as both a clock and a small information screen.

The goal is to make the time display stay perfectly synced with zero-second error, while also letting users change the background wallpaper and check live weather status directly on the touch screen.
